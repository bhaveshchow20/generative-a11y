## Install the core and browser packages

Core decides what to announce and when. DOM adds those announcements to the
page. Add a framework adapter only when your app needs one.

{/* prettier-ignore */}
```shell
npm install @generative-a11y/core @generative-a11y/dom
```

### Walkthrough

<Steps>

<Step>

### Add the core runtime

@generative&#45;a11y/core turns app events into useful screen&#45;reader updates
and controls their timing.

</Step>

<Step>

### Add browser delivery

@generative&#45;a11y/dom adds those updates to the page without changing the
visible interface.

</Step>

</Steps>

<span id="minimal&#45;integration"></span>

## Minimal integration

Create one runtime and connect it to the browser. Send only the new text from
each streaming update. Report when the response finishes, fails, or stops.
Dispose both resources when the session ends.

{/* prettier-ignore */}
```typescript
import { createGenerativeA11y } from "@generative-a11y/core";
import { connectRuntimeToDOM } from "@generative-a11y/dom";

const runtime = createGenerativeA11y({});
const delivery = connectRuntimeToDOM(runtime);

runtime.dispatch({ type: "response.started", responseId: "response-1" });
runtime.dispatch({
  type: "response.text.delta",
  responseId: "response-1",
  delta: "A complete sentence.",
});
runtime.dispatch({ type: "response.completed", responseId: "response-1" });

delivery.dispose();
runtime.dispose();
```

### Walkthrough

<Steps>

<Step>

### Create one runtime

Your runtime tracks responses, prepares useful text, and controls update timing.

</Step>

<Step>

### Connect the browser

connectRuntimeToDOM creates and manages the hidden live regions used for
screen&#45;reader updates.

</Step>

<Step>

### Report app events

Tell the runtime when a response starts, receives text, and finishes.

</Step>

<Step>

### Clean up

Dispose the browser connection first, then dispose the runtime when the session
ends.

</Step>

</Steps>

<Callout title="Evidence and testing note">

generative&#45;a11y can confirm when it adds an announcement to the page. Test
with real screen readers to confirm what people hear.

</Callout>
