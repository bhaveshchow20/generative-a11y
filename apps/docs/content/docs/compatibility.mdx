## Browser and server support

Core works without a browser. DOM stays inactive when document is unavailable.
React renders stable hidden regions on the server and connects them in the
browser. Adapter imports do not require browser globals.

<span id="browser&#45;matrix"></span>

## Automated browser tests have limits

Browser tests run in Chromium, Firefox, and WebKit. WebKit provides useful
coverage, but it cannot replace Safari testing with a real screen reader. Record
those hands&#45;on tests separately.

## Development package compatibility

The headless devtools store and test recorder work with the public core
contracts. The optional browser overlay has React peers. Testing helpers accept
Vitest structurally and do not add a test&#45;runner peer to core.
