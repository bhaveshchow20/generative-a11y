<span id="installation"></span>

## Install the assistant&#45;ui adapter

Install @generative&#45;a11y/core, @generative&#45;a11y/dom, and
@generative&#45;a11y/assistant&#45;ui beside assistant&#45;ui. The adapter
subscribes to a thread runtime you already own and leaves rendering, actions,
and focus behavior with the host application.

<span id="bind"></span>

## Connect an existing thread runtime

bindThreadRuntime reads only getState and subscribe. It cannot run thread
actions, render an interface, or dispose your core runtime.

{/* prettier-ignore */}
```typescript
import { bindThreadRuntime } from "@generative-a11y/assistant-ui";

const binding = bindThreadRuntime({
  runtime,
  scopeId: "support-thread",
  thread,
});

// Removes only the subscription it created.
binding.dispose();
```

<span id="lifecycle&#45;mapping"></span>

## Lifecycle mapping

Documented thread state supplies response text, final states, tool progress,
approvals, and sources. The binding records existing history before it starts
dispatching, which prevents old messages from becoming new announcements after
hydration.

<span id="screen&#45;reader&#45;behavior"></span>

## Expected screen&#45;reader behavior

New response text becomes paced announcement intents. Tool and approval changes
receive priority based on the shared policy, while routine status changes leave
focus in place. Browser transcripts show what the DOM package wrote; confirm
spoken output with the screen readers and browsers your application supports.

<span id="limits"></span>

## What public state cannot prove

Your adapter can report streaming, known final states, tools, approvals, and
sources. assistant&#45;ui does not provide general retry or connection events,
so generative&#45;a11y does not guess.

<span id="troubleshooting"></span>

## Troubleshooting

Repeated historical messages can indicate that a new binding received a
different scopeId or started before thread hydration settled. Missing updates
can indicate that the supplied thread does not expose the expected public state.
Check one active subscription, stable identity, and the documented
assistant&#45;ui version before changing announcement policy.
