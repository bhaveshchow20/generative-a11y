## Use the AG&#45;UI adapter

CopilotKit v2 exposes an AG&#45;UI agent through useAgent. Bind only after
isReady, use a stable scope, and dispose the subscription from the effect
cleanup.

{/* prettier-ignore */}
```tsx
import { useEffect, useId } from "react";
import { useAgent } from "@copilotkit/react-core/v2";
import { bindAgent } from "@generative-a11y/ag-ui";
import type { GenerativeA11yRuntime } from "@generative-a11y/core";

interface CopilotKitAccessibilityProps {
  agentId: string;
  runtime: Pick<GenerativeA11yRuntime, "dispatch">;
}

export function CopilotKitAccessibility({
  agentId,
  runtime,
}: CopilotKitAccessibilityProps) {
  const bindingScopeId = useId();
  const { agent, isReady } = useAgent({ agentId });

  useEffect(() => {
    if (!isReady) return;
    const binding = bindAgent({
      agent,
      runtime,
      scopeId: `copilotkit:${bindingScopeId}`,
    });
    return () => binding.dispose();
  }, [agent, isReady, runtime, bindingScopeId]);

  return null;
}
```

### Wait for readiness

CopilotKit v2 exposes a public AG&#45;UI agent, so the AG&#45;UI adapter can

</Step>

React effect cleanup disposes exactly the subscription created by this mount.

</Step>

## Why there is no CopilotKit package

A second adapter would duplicate the same work. If an app has client tools that
AG&#45;UI cannot identify, connect those tools directly instead of guessing from
their names.
