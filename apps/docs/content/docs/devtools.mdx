## Install development&#45;only diagnostics

Install @generative&#45;a11y/devtools in development environments. The package
observes public core diagnostics and does not patch dispatch, change
announcement policy, or depend on an AI framework.

{/* prettier-ignore */}
```shell
npm install --save-dev @generative-a11y/devtools
```

### Walkthrough

<Steps>

<Step>

### Keep it development&#45;only

The package helps inspect runtime behavior and should not become part of the
production accessibility path.

</Step>

<Step>

### Attach an existing runtime

The store borrows public diagnostic methods from a runtime your app owns.

</Step>

</Steps>

<span id="trace&#45;explorer"></span>

## Open the Accessibility Trace Explorer

The optional overlay mounts only when your code calls mountDevtoolsOverlay. It
starts collapsed inside an open Shadow DOM and provides search, filters, causal
evidence, capture controls, and explicit trace copy.

{/* prettier-ignore */}
```typescript
import { createDevtoolsStore } from "@generative-a11y/devtools";
import { mountDevtoolsOverlay } from "@generative-a11y/devtools/overlay";

const store = createDevtoolsStore({ maxEntries: 250 });
const detach = store.attachRuntime({ id: "support", runtime });
const overlay = mountDevtoolsOverlay({ store });

// Dispose in reverse ownership order.
overlay.dispose();
detach();
store.dispose();
```

### Walkthrough

<Steps>

<Step>

### Create a bounded store

maxEntries limits retained diagnostic records and reports how many older records
were dropped.

</Step>

<Step>

### Attach one runtime identity

A stable runtime ID connects observed events, decisions, snapshots, and optional
DOM delivery results.

</Step>

<Step>

### Mount the overlay

The browser helper creates the launcher and trace workspace only after this
explicit call.

</Step>

<Step>

### Dispose owned resources

Close the overlay, detach the borrowed runtime, then dispose the store.

</Step>

</Steps>

<span id="captured&#45;evidence"></span>

## Captured evidence and redaction

The store retains event categories, outcomes, timing, stable IDs, queue and
entity snapshots, declared adapter evidence, and browser delivery metadata. It
excludes assistant text, labels, errors, tool data, stacks, DOM content,
deduplication keys, and timer handles.

Pass adapter metadata through source only when a documented integration can
support it. Devtools does not detect a framework or invent events that the
framework did not report.

<span id="delivery&#45;correlation"></span>

## Correlate runtime decisions with DOM delivery

Send DOMDeliveryResult values from createDOMAnnouncer onDiagnostic to
store.recordDelivery. Safe announcement and entity IDs connect the browser
action to the runtime decision that requested it.

<Callout title="Evidence and testing note">

A trace can confirm a runtime decision and a browser API call or live&#45;region
mutation. It cannot prove that assistive technology spoke the announcement.

</Callout>

<span id="keyboard&#45;and&#45;focus"></span>

## Overlay keyboard and focus behavior

Opening the workspace moves focus into it. Escape or the close control collapses
the workspace and restores the element focused before opening. Streaming records
do not move focus, the overlay does not trap focus, and it creates no live
region or global keyboard shortcut.
