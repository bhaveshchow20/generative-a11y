## Check which events the adapter can see

Each adapter lists the events its framework reports and the events that are
unavailable. Adapters do not guess by reading rendered text, timing interface
changes, or using private framework fields.

Use the core integration directly when your app knows about retries, connection
changes, or custom interactions that the framework adapter cannot see.

## Install only the layers you use

Your app supplies a core runtime to its framework adapter. DOM or React handles
browser announcements separately.

- Custom browser application: @generative&#45;a11y/core and
  @generative&#45;a11y/dom
- React application: @generative&#45;a11y/core and @generative&#45;a11y/react
- AI SDK: add @generative&#45;a11y/ai&#45;sdk to the core and delivery layers
- assistant&#45;ui: add @generative&#45;a11y/assistant&#45;ui to the core and
  delivery layers
- AG&#45;UI or CopilotKit v2: add @generative&#45;a11y/ag&#45;ui to the core and
  delivery layers
