## AnnouncementIntent

An AnnouncementIntent describes an update prepared by core. It does not confirm
that the browser delivered it or that a screen reader spoke it.

## AnnouncementDiagnostic

Diagnostics record runtime decisions for tests and telemetry. Listener failures
do not change runtime behavior. Repeated queue&#45;limit decisions can share one
diagnostic with a count.

## Versioned runtime observability

subscribeDiagnosticEvents emits each normalized source event before the
decisions caused by that dispatch. getDiagnosticSnapshot returns current
lifecycle and queue timing without response text, labels, errors, scopes,
deduplication keys, or timer handles.
