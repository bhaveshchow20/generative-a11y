## Signature and import

Create one runtime for your app or for each conversation that needs separate
settings. Connect delivery before sending events that can produce output.

{/* prettier-ignore */}
```typescript title="accessibility-runtime.ts"
import { createRuntime } from "@generative-a11y/core";

const runtime = createRuntime({
  onAnnouncement(intent) {
    console.log(intent.text);
  },
});
```

Browser apps usually connect output with [bindRuntime](/api/dom/bind-runtime).
Use `onAnnouncement` when your app owns another delivery mechanism.

## Complete response lifecycle

Each delta contains only new text. A completed event announces useful text that
is still waiting, then closes the response.

{/* prettier-ignore */}
```typescript title="Response lifecycle"
const accepted = runtime.dispatch({
  type: "response.started",
  responseId: "report-1",
});

runtime.dispatch({
  type: "response.text.delta",
  responseId: "report-1",
  delta: "The migration completed successfully.",
});

runtime.dispatch({
  type: "response.completed",
  responseId: "report-1",
});

console.log({ accepted, pending: runtime.pendingCount() });

// Call when the owning surface is removed, after delivery is no longer needed.
function disposeRuntime() {
  runtime.dispose();
}
```

Send `response.started` before deltas or terminal events for that response.
Completion cancels response timers; call `dispose()` when the runtime owner
ends.
