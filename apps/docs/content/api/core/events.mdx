## Response replacement example

Use responseInstanceId when one logical response can be replaced. Late events
from the old instance are suppressed as stale.

{/* prettier-ignore */}
```typescript
runtime.dispatch({
  type: "response.retrying",
  responseId: "report",
  responseInstanceId: "attempt-1",
  nextResponseInstanceId: "attempt-2",
  attempt: 2,
});
```
