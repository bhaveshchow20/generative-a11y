## Signature and cleanup

Most apps should use createGenerativeA11y. Use the scheduler directly only if
your app already decides which events should produce announcements.

{/* prettier-ignore */}
```typescript
const scheduler = createAnnouncementScheduler({
  clock,
  minimumGapMs: 750,
  dedupeWindowMs: 4_000,
  maxQueueSize: 64,
  onAnnouncement: deliver,
  onDiagnostic: recordDiagnostic,
});

scheduler.schedule({
  channel: "polite",
  text: "The report is ready.",
  sourceType: "response.completed",
  scope: "response:report-1",
  capacityPriority: "content",
});
```
