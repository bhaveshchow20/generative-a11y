## Connect your runtime

Pass your existing `agent` and core `runtime`. The binding observes public state
and callbacks; your app owns execution and browser delivery.

```ts title="agent-accessibility.ts"
import { bindAgent } from "@generative-a11y/ag-ui";

const binding = bindAgent({ runtime, scopeId: "research-agent", agent });

// Call binding.dispose() when the owning scope ends.
```

See [bindAgent](/api/ag-ui/bind-agent) for options and
[the integration guide](/docs/integrations/ag-ui) for setup and compatibility.

## Events the adapter can report

AG&#45;UI 0.0.59 reports exact run and delegated subagent identity. Step events
expose labels but no stable IDs, making step and hierarchy support partial.
Replay and reconnection are partial because there is no mandatory persistent
cursor; retry support remains unavailable.

AG&#45;UI integration never uses private observables or guesses events missing
from the protocol.

## Localized announcements

See [catalogs and adapter copy](/docs/localized-announcements) for the typed
`messages` and `copy` options, language ownership, validation, construction
lifetime, and replay requirements. Existing lifecycle evidence and timing remain
unchanged.
