## Events the adapter can report

AG&#45;UI 0.0.59 reports exact run and delegated subagent identity. Step events
expose labels but no stable IDs, making step and hierarchy support partial.
Replay and reconnection are partial because there is no mandatory persistent
cursor; retry support remains unavailable.

<Callout title="Evidence and testing note">

AG&#45;UI integration never uses private observables or guesses events missing
from the protocol.

</Callout>
