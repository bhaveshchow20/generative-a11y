## Signature and import

Create the binding after the agent is ready, then dispose it when the owning
application scope ends.

{/* prettier-ignore */}
```typescript
import { bindAgent } from "@generative-a11y/ag-ui";

const binding = bindAgent({
  runtime,
  scopeId: "research-agent",
  agent,
  maxTrackedEntities: 1_000,
});

// Unsubscribes without disposing agent or runtime.
binding.dispose();
```

### Walkthrough

<Steps>

<Step>

### Connect the agent

AgentBinding subscribes to documented callbacks without running your agent.

</Step>

<Step>

### Separate agent IDs

scopeId prevents run, message, tool, and interrupt IDs from colliding across
agents.

</Step>

<Step>

### Limit stored IDs

After reaching its limit, the adapter ignores new IDs instead of removing active
records.

</Step>

<Step>

### Dispose the subscription

Your app still owns the runtime and agent after the binding is disposed.

</Step>

</Steps>

<Callout title="Declared fidelity">

AG&#45;UI 0.0.59 provides stable run and subagent IDs. Step callbacks provide
`stepName` but no stable step ID, so step and hierarchy fidelity are partial.
Replay and reconnection are partial, retry support is unavailable, and custom
events require an explicit host mapping.

</Callout>
