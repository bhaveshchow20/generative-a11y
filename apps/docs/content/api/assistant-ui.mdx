## Events the adapter can report

Public thread state can report interruptions but not general retries or
connection changes. Tool failures and sources depend on content parts from
assistant&#45;ui.

<Callout title="Evidence and testing note">

Missing events are never guessed from rendered text, timing, or private runtime
fields.
