## Install and import

Core does not depend on the DOM, React, or an AI framework. Your app sends it
RuntimeEvent objects, and it creates AnnouncementIntent objects when there is
something useful to announce.

{/* prettier-ignore */}
```shell title="Terminal"
npm install @generative-a11y/core
```

Use core in any JavaScript runtime, including tests without a document. Browser
apps add [DOM](/api/dom) or [React](/api/react) for delivery.

```ts title="accessibility-runtime.ts"
import { createRuntime } from "@generative-a11y/core";

const runtime = createRuntime({
  onAnnouncement: (intent) => console.log(intent.text),
});

// Call runtime.dispose() when its owner ends.
```

This listener records prepared output. Connect browser delivery before sending
lifecycle events in a web app.

## Messages

English notices work without configuration. For custom copy, import `en` and
`Messages` from `@generative-a11y/core/messages` and pass `messages` to
`createRuntime`. This entry point also exports `MessageMap`, `MessageParams`,
`MessageKey`, `AdapterCopy`, and `normalizeAdapterCopy`. These exports are not
available from the core root.

See [localized announcements](/docs/localized-announcements) for examples and
[API naming changes](/docs/stability#public-api-naming-update) for the breaking
rename reference.
