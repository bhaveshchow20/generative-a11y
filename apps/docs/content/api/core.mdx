## Install and import

Core does not depend on the DOM, React, or an AI framework. Your app sends it
GenerativeA11yEvent objects, and it creates AnnouncementIntent objects when
there is something useful to announce.

{/* prettier-ignore */}
```shell
npm install @generative-a11y/core
```

### Walkthrough

<Steps>

<Step>

### Install core

Use core in any JavaScript runtime, including tests that do not have a document.

</Step>

<Step>

### Add browser delivery
