## Install browser delivery

DOM uses core without depending on React or an AI framework.

{/* prettier-ignore */}
```shell title="Terminal"
npm install @generative-a11y/core @generative-a11y/dom
```

Core prepares announcement intents; DOM delivers them with `ariaNotify` when
available and hidden live regions as a fallback. See
[bindRuntime](/api/dom/bind-runtime) for connection and cleanup.
