## Signature and import

Create one binding per thread scope and dispose it when that subscription owner
unmounts.

{/* prettier-ignore */}
```typescript title="thread-accessibility.ts"
import { bindThread } from "@generative-a11y/assistant-ui";

const binding = bindThread({
  runtime,
  scopeId: "support-thread",
  thread,
});

// Call when the owning scope ends; removes only subscription and adapter state.
function disposeThreadBinding() {
  binding.dispose();
}
```

Keep `scopeId` stable and unique across mounted conversations. The binding uses
only `getState` and `subscribe`; disposal releases the subscription and adapter
records while preserving your thread and core runtimes.

After the tracking limit is exhausted, the binding suppresses subsequent
lifecycle events, including events for known identities. Create a fresh binding
at an intentional session boundary to resume observation.
