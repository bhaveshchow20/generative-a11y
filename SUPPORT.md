# Support

`generative-a11y` is in pre-release development. APIs may change, and the
packages are not yet published to npm.

## Where to ask

- Use a
  [bug report](https://github.com/bhaveshchow20/generative-a11y/issues/new?template=bug_report.yml)
  for a reproducible problem.
- Use a
  [feature request](https://github.com/bhaveshchow20/generative-a11y/issues/new?template=feature_request.yml)
  for an integration or behavior proposal.
- Use an
  [assistive-technology test report](https://github.com/bhaveshchow20/generative-a11y/issues/new?template=assistive_technology_report.yml)
  to share a manual test result, including positive findings.
- Use
  [GitHub's private vulnerability reporting](https://github.com/bhaveshchow20/generative-a11y/security/advisories/new)
  for security issues.

Before opening an issue, search existing issues and include the smallest useful
reproduction. For accessibility behavior, include the assistive technology,
browser, operating system, input method, and exact versions when possible.

Maintainers may convert support requests into focused bug or feature issues.
